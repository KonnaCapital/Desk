# Security policy

Please report suspected vulnerabilities privately through a
[GitHub Security Advisory](https://github.com/KonnaCapital/desk/security/advisories/new).
Do not put exploit details, credentials, personal data, or private board data
in a public issue or pull request.

Include the affected version or commit, platform, a concise reproduction, and
the impact. Redact any local paths or data that could identify a person. The
maintainer will use the private advisory to coordinate validation and a fix.

Desk is local-first. It does not provide an account, cloud sync, updater, or
remote data service. That does not remove the need to report a local privilege,
data exposure, injection, or installer problem privately.

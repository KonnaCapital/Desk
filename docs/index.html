Desk

Two things on your desktop: a local kanban and a pin-able timer.

Desk saves on this machine. No account, no phone, no cloud. Pin it to the corner when everything else is loud.

Before you install

Windows: the x64 NSIS installer uses a current-user install and includes English and Finnish text. It is unsigned unless the maintainer has configured the documented certificate secrets, so SmartScreen may warn.

macOS: the universal Apple Silicon + Intel DMG is configured in CI, but stable Mac support remains unverified until a real macOS runtime check, Developer ID signing, and notarization. The public download link appears only after those checks; an unsigned CI preview is kept as an Actions artifact.

Your data

Desk keeps board.json and, when available, board.backup.json in:

  • Windows: %LOCALAPPDATA%\com.konnacapital.desk
  • macOS: ~/Library/Application Support/com.konnacapital.desk

Complete removal

Windows: quit Desk, uninstall it from Settings → Apps → Installed apps, then delete the Windows data folder above if it remains. The installer removes only Desk's own Run-key autostart value; Delete App Data is an explicit installer option.

macOS: before deleting the app, open Desk Settings and turn off Launch Desk at login. Then quit Desk, move Desk.app to the Trash, and delete the macOS data folder above. If the setting cannot be opened, the plugin's derived fallback is ~/Library/LaunchAgents/{app_name}.plist; inspect the candidate's Label and ProgramArguments first. The exact Desk filename must be confirmed in the real-Mac gate, so do not assume one or delete unrelated plists.

Ennen asennusta

Windows: x64-NSIS-asennus on käyttäjäkohtainen ja sisältää englannin ja suomen. Asennin on allekirjoittamaton, ellei ylläpitäjä ole määrittänyt dokumentoituja varmenteita, joten SmartScreen voi varoittaa.

macOS: Apple Silicon- ja Intel-koneille tarkoitettu DMG on määritetty CI:ssä, mutta Macin vakaa tuki on vielä varmistamatta. Tarvitaan oikea macOS-ajotesti, Developer ID -allekirjoitus ja notarisaatio. Julkinen latauslinkki avautuu vasta niiden jälkeen; allekirjoittamaton CI-esikatselu säilyy Actions-artefaktina.

Omat tietosi

Desk säilyttää tiedostot board.json ja mahdollisen board.backup.json näissä kansioissa:

  • Windows: %LOCALAPPDATA%\com.konnacapital.desk
  • macOS: ~/Library/Application Support/com.konnacapital.desk

Poista kaikki

Windows: sulje Desk, poista se kohdasta Asetukset → Sovellukset → Asennetut sovellukset ja poista yllä oleva Windowsin datakansio, jos se jäi jäljelle. Asennin poistaa vain Deskille kuuluvan Run-avaimen automaattikäynnistyksen; Delete App Data on erikseen valittava asetus.

macOS: ennen sovelluksen poistamista avaa Desk Asetukset ja poista käytöstä Käynnistä Desk kirjautumisen yhteydessä. Sulje Desk, siirrä Desk.app roskakoriin ja poista yllä oleva macOS-datakansio. Jos asetusta ei voi avata, lisäkäynnistyksen johdettu varapolku on ~/Library/LaunchAgents/{app_name}.plist; tarkista ehdokkaan Label ja ProgramArguments ennen poistamista. Tarkka Desk-tiedostonimi on vahvistettava oikean Macin portissa, joten älä arvaa nimeä tai poista muita plist-tiedostoja.

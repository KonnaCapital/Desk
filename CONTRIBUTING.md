# Contributing

One change per pull request. `main` is the published promise: a local kanban and a pin-able timer.

## Before you open a PR

- Keep the change one idea.
- Run `npm test`.
- Do not add a feature that is not “two things on this machine”.

## Parked (later PRs only)

- Phone / remote capture
- MCP
- Markdown or Obsidian vault
- Mac or Linux packages
- winget / Scoop / MSI beside the NSIS installer
- Code signing
- Extra languages beyond Finnish and English

If the idea is shiny and adjacent, write it down and stop. Do not fold it into an unrelated PR.
